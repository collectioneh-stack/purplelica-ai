> "이거 프롬프트 어떻게 짜야 돼요?"
>
> AI 처음 만나신 분들이 가장 부담스러워하는 단어가 바로 **프롬프트(Prompt)** 입니다.
> 사실은 별거 아닙니다. 차근차근 풀어드립니다.

---

## 한 줄 정의

> **프롬프트(Prompt) = AI한테 시키는 일 한 마디.**

ChatGPT 입력창에 우리가 적는 문장 — 그게 전부 프롬프트입니다.

## 🍞 쉽게 말하면

음식점에서 종업원한테 주문하는 것과 똑같습니다.

- **"김치찌개 하나 주세요"** → 종업원한테 보내는 주문
- **"내일 회의 자료 한 페이지로 요약해줘"** → ChatGPT한테 보내는 프롬프트

차이는 단 하나, 종업원 대신 AI가 받습니다.

## 💼 실무 예시

### 예시 1: 마트 직원 — 회의록 정리

오늘 점장 회의가 1시간 있었다고 가정해봅시다. 회의 메모를 종이에 휘갈겨놓고 정리해야 합니다.

**나쁜 프롬프트 (모호함)**
```
정리해줘
```

**좋은 프롬프트 (구체적)**
```
아래 회의 메모를 다음 형식으로 정리해줘:
1. 결정된 사항 (불릿)
2. 액션 아이템 (담당자/기한 포함)
3. 다음 회의 안건

메모: [여기에 메모 붙여넣기]
```

같은 AI여도 **프롬프트 한 줄 차이로 결과가 완전히 달라집니다.**

### 예시 2: 자영업자 — 단골 고객 답장

```
아래 고객 리뷰에 사장이 직접 쓴 것처럼 따뜻한 답글을 써줘.
조건: 3문장 이내, "감사합니다" 같은 인사로 끝.

리뷰: "맛은 있는데 좀 짰어요."
```

→ 곧바로 사용 가능한 답글이 나옵니다.

## 좋은 프롬프트의 핵심 3가지

| 요소 | 설명 | 예시 |
|:---|:---|:---|
| **역할** | "너는 누구냐"를 알려주기 | "너는 10년차 마케터야" |
| **출력 형식** | 어떻게 답할지 명시 | "표로 정리해줘", "3문장 이내" |
| **맥락/자료** | 참고할 내용 같이 주기 | "다음 회의록을 보고…", "이 글을 참고해서…" |

**쉽게 말하면**: 신입한테 일 시킬 때 "이게 뭔지 알고, 어떻게 해야 하고, 자료는 여기 있다"를 한 번에 알려주는 것과 같습니다.
