회의 끝나고 회의록 정리하라는 말, 들을 때마다 한숨 나오지 않으세요?

30분짜리 회의였는데 회의록 정리하는 데 또 30분. 누가 뭐라고 했는지 기억이 가물가물하고, 정리해서 공유하면 "이 내용 빠졌는데?"라는 피드백까지.

저도 매주 3~4개 회의에 참석하면서 같은 고통을 겪었습니다.

## "회의록 정리 좀 해줄래?" — 왜 이게 이렇게 고통스러울까

솔직히 회의록 정리가 어려운 건 아닙니다. 그냥 **귀찮고 시간이 아깝죠.**

더 문제는 이겁니다:

- 회의 중에 받아적은 메모가 나중에 보면 해독 불가
- "이거 누가 하기로 했지?" → 기억이 안 남
- 정리에 30분 쓰고 나면, 정작 내 업무할 시간이 사라짐

쉽게 말하면, 회의록 정리는 **나한테 아무런 성과도 안 되는 일**인데 매번 시간을 빼앗기는 겁니다.

그런데 이걸 ChatGPT로 10분 안에 끝낼 수 있습니다.

## 프롬프트 1: 회의 내용 구조화

회의 중에 대충 적어놓은 메모를 ChatGPT에 넣고 이 프롬프트를 사용합니다.

```
너는 10년차 프로젝트 매니저야.
아래 회의 메모를 다음 형식으로 정리해줘:

1. 회의 요약 (3줄 이내)
2. 주요 논의 사항 (번호 매겨서)
3. 결정된 사항
4. 액션아이템 (담당자 | 내용 | 마감일) — 표 형태로

[여기에 회의 메모 붙여넣기]
```

**핵심 포인트**: "10년차 프로젝트 매니저"라는 역할을 지정하면, AI가 단순 정리가 아니라 **실무적으로 중요한 항목을 알아서 분류**합니다.

메모가 두서없어도 괜찮습니다. "김 과장이 말하길 다음 주까지 디자인 시안 달라고 했고 박 대리가 일정 빠듯하다고 했음" 이 정도만 넣어도 표로 정리해줍니다.

## 프롬프트 2: 빠진 내용 체크

정리된 회의록을 보고 "이거 빠진 거 없나?" 불안할 때 씁니다.

```
아래 회의록에서 빠졌을 가능성이 있는 항목을 점검해줘:

- 결정되지 않고 보류된 안건이 있는가?
- 담당자가 지정되지 않은 액션아이템이 있는가?
- 다음 회의 일정이 언급되었는가?

[회의록 붙여넣기]
```

이걸 돌리면 "보류된 안건 1건: 예산 승인 건 — 다음 주 재논의 필요"처럼 **내가 놓친 부분을 자동으로 찾아줍니다.**

실제로 저는 이 프롬프트로 빠뜨린 액션아이템을 3번이나 잡아냈습니다. 나중에 "왜 안 했어?"라는 소리 듣는 것보다 10배 낫죠.

## 프롬프트 3: 공유용 요약본 생성

팀 채팅방에 올릴 짧은 버전이 필요할 때 씁니다.

```
아래 회의록을 팀 메신저(슬랙/카카오톡)에 공유할 수 있게 요약해줘.
조건:
- 10줄 이내
- 이모지 사용하지 말 것
- 액션아이템은 "ㅁ 담당자: 내용 (마감일)" 형식
- 톤: 간결하고 프로페셔널하게

[회의록 붙여넣기]
```

긴 회의록을 슬랙에 올리면 아무도 안 읽습니다. 10줄로 요약해서 올리면 "회의록 정리 잘하네"라는 평가까지 따라옵니다.

## 실전 워크플로우: 회의 끝나고 10분

| 단계 | 시간 | 작업 |
|:---:|:---:|:---|
| 1 | 0~2분 | 회의 중 메모 복사해서 ChatGPT에 붙여넣기 |
| 2 | 2~5분 | 프롬프트 1로 구조화 → 결과 확인 및 수정 |
| 3 | 5~7분 | 프롬프트 2로 빠진 내용 체크 |
| 4 | 7~10분 | 프롬프트 3으로 공유용 요약 생성 → 팀 채널에 공유 |

**30분 걸리던 작업이 10분으로 줄어듭니다.** 남는 20분으로 진짜 내 업무를 하세요.

## 한 가지 주의할 점

회의 내용에 **고객 개인정보, 급여 정보, 미공개 사업 전략** 같은 민감한 정보가 있다면 ChatGPT에 그대로 넣지 마세요.

이런 경우에는:
- 민감한 이름을 "A 고객", "B 프로젝트"로 바꿔서 넣거나
- 회사에서 승인한 AI 도구(예: Microsoft Copilot 기업용)를 사용하세요

## 정리

회의록 정리가 귀찮았던 건 능력 문제가 아닙니다. 그냥 비효율적인 방식으로 하고 있었던 겁니다.

프롬프트 3개만 저장해두면:
- 회의록 정리 시간 30분 → 10분
- 빠진 항목 자동 체크
- 공유용 요약까지 한 번에

이 글에서 소개한 프롬프트를 복사해서 바로 써보세요. 오늘 회의부터 달라집니다.
