"AI로 업무를 자동화하고 싶은데, 막상 뭐부터 배워야 할지 막막하신가요?" 클로드 코드는 내 컴퓨터 안에서 파일 정리·문서 작성·반복 업무를 대신 해주는 AI 비서입니다. 쉽게 말하면, 프로그램을 다루듯 명령하는 게 아니라 사람에게 말하듯 시키면 되는 도구예요. 이 시리즈는 그 사용법을 초보 눈높이에서 30편으로 나눠 연재합니다. 이 글은 전체 지도이니 저장해두고 필요한 편부터 찾아보셔도 됩니다.

## 한눈에 (이 시리즈로 얻는 것)

- 클로드 코드를 처음부터 설치하고 첫 작업을 시켜볼 수 있습니다.
- 반복 업무를 명령·자동화로 바꾸는 방법을 순서대로 익힙니다.
- 비개발자도 각 편의 '복붙 자산'(명령어·프롬프트)만 가져가면 바로 씁니다.

## 1부. 시작하기 (초급)

1. 클로드 코드란 무엇인가 — 내 컴퓨터에서 일하는 AI 비서
2. 첫 대화 — 무엇을 어떻게 물어볼까
3. 파일 읽고 고치기 — 직접 안 열어도 된다
4. 슬래시 명령 기본 — help·clear·compact
5. CLAUDE.md — AI에게 내 규칙을 기억시키기
6. 권한 시스템 — 위험한 건 물어보게, 안전한 건 자동으로

## 2부. 제대로 쓰기 (중급)

7. 계획 모드 — 실행 전 설계부터
8. init — 프로젝트 자동 파악시키기
9. 이미지 붙여넣기 — 스크린샷으로 시키기
10. 웹 검색·페치 — 최신 정보 가져와 작업
11. Git 통합 — 커밋·기록을 말로
12. 커스텀 슬래시 명령 — 내 반복 업무를 명령으로
13. 스킬 — 전문 작업 매뉴얼 심기
14. 메모리 — 중요한 걸 계속 기억시키기

## 3부. 자동화·확장 (고급)

15. 서브에이전트 — 여러 AI에게 나눠 맡기기
16. 훅 — 특정 순간 자동 실행·차단
17. MCP — 외부 도구·서비스 연결
18. 백그라운드 작업 — 오래 걸리는 건 뒤에서
19. 헤드리스 모드 — 화면 없이 스크립트로
20. 크론 자동화 — 정해진 시각에 알아서
21. 세션 재개 — 이어서 하기
22. 워크트리 — 안전하게 실험하기
23. 모델 선택 — 작업에 맞는 두뇌 고르기

## 4부. 실전 세팅 (마스터)

24. settings.json — 내 클로드 커스터마이징
25. 상태줄 — 터미널에 내 정보 표시
26. 원격·모바일 조종 — 폰에서 내 컴퓨터 AI 부리기
27. IDE 통합 — 에디터 안에서
28. 컨텍스트 관리 — 길어진 대화 다루기
29. 팀 공유 — 설정을 함께 쓰기
30. 안전 수칙·모범 사례 — 사고 없이 오래 쓰기

## 이렇게 활용하세요

처음이라면 1편부터 순서대로, 특정 기능이 급하다면 목차에서 바로 그 편으로 가시면 됩니다. 각 편은 '이 기능이 무엇인지 → 사용법 → 실생활 예시 → 바로 복사해 쓰는 명령·프롬프트' 순으로 짧게 정리합니다. 이 목차를 저장해두고, 새 편이 올라올 때마다 하나씩 채워가 보세요. 다 읽고 나면 업무 자동화의 큰 그림이 손에 잡힐 겁니다.
